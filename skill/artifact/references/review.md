# 发布前自查

`art check` 只能发现机械问题。下面这些要你自己看。按顺序过一遍，每项都确认了再发布。

## 1. 目的

- [ ] 能用一句话说出这页的目的，并且打开页面第一屏就能看出来。
- [ ] 标题是一个具体的名字，能和用户的其他页面区分开。

## 2. 事实

- [ ] 每个数字、日期、人名、产品名都核对过，来自用户提供的材料或可靠来源。
- [ ] 没有为了显得具体而编造的数字、引语、案例。示例数据已标注“示例”。
- [ ] 外部链接能打开，指向正确的页面。
- [ ] 估算、推断都写明了是估算或推断，以及依据。

## 3. 逻辑

- [ ] 每个结论都有对应的依据，依据就在附近。
- [ ] 因果关系是真的因果，不只是时间上先后发生。
- [ ] 前后没有矛盾：摘要里的数字和正文、图表里的一致。
- [ ] 同一个东西全文用同一个名字。
- [ ] 段落顺序是读者需要的顺序，不是你做事的顺序。

## 4. 语言

- [ ] 从头读一遍。凡是需要回头重读才明白的句子，都改了。
- [ ] 删掉了重复标题的开场句、每段末尾的小结、全文末尾的“总结”。
- [ ] 没有 `writing-zh.md` 第 3 节列出的 AI 腔：空泛大词、夸张形容、套话连接、宏大开场、结尾升华、句式套路。
- [ ] 加粗、感叹号、破折号都很克制：一屏加粗不超过两三处，没有感叹号。
- [ ] 结尾停在结论、待决定的事项或下一步行动上。

## 5. 中文排版

- [ ] 中英文、中文与数字之间有空格。
- [ ] 中文句子用全角标点；引号是“”；省略号是……。
- [ ] 数字、日期、单位的写法全文统一。
- [ ] 专有名词大小写正确。

## 6. 图与版式

- [ ] 每张图都在说一件具体的事，都有图注；没有纯装饰的图。
- [ ] 机制有示意图，数字有图表，多属性比较有表格。
- [ ] 图表的颜色和文字在暗色主题下也看得清。
- [ ] 手机宽度下没有横向滚动、没有被截断的文字、没有挤在一起的元素。
- [ ] 没有 `design.md` 第 9 节列出的模板化痕迹。
- [ ] 最后删掉了一个不服务于内容的装饰。

## 7. 交互（有交互时）

- [ ] 页面一打开就处于可用状态，有数据或标明“示例”的数据。
- [ ] 每个按钮都有效果，文字写明点了会怎样。
- [ ] 出错时有说明和解决办法；存储不可用时页面照常工作。

## 8. 看一眼

如果环境能截图或打开浏览器，看一次桌面宽度和手机宽度的效果，按看到的问题改一轮，然后发布。不要反复截图循环，用户在等链接。
