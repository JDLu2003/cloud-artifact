# 幻灯片

做演示稿时读。从 `assets/templates/deck.html` 复制一份开始，它已经处理好 16:9 缩放、键盘翻页、触屏滑动、页码、全屏、总览和打印。

## 1. 先确认是不是该做幻灯片

幻灯片适合有人讲、有人听的场合。如果用户要的是发出去让人自己读的材料，做成文档更好：文档能放下完整的论证，幻灯片放不下。拿不准时问一句。

## 2. 模板用法

```html
<section class="slide">
  <h2>华东区贡献了本季度 62% 的新增收入</h2>
  …内容…
  <aside class="notes">演讲者备注：这里展开讲上海和杭州两个城市。</aside>
</section>
```

- 每个 `<section class="slide">` 是一页，画布固定 1280×720，模板会等比缩放到窗口大小。按画布尺寸写样式，不用考虑屏幕大小。
- 常用版式类：`cover`（封面）、`split`（左文右图）、`stat`（关键数字）、`full`（整页图表）、`dark`（深色页）。可以自己加。
- 快捷键：←/→ 或空格翻页，`F` 全屏，`O` 总览，`N` 显示备注。地址栏 `#5` 直接跳到第 5 页。
- 写完删除模板顶部的 `TEMPLATE-SAMPLE` 注释和全部示例页。

## 3. 每一页

- **一页一个观点。** 标题就是这个观点，写成完整的判断句：`华东区贡献了 62% 的新增收入`，不写 `区域分析`。只看标题连起来，应该就是整个演讲的论证。
- **每页都有视觉元素**：图表、示意图、截图、关键数字或图标。纯文字页让人记不住。
- **字少**：正文不超过三条，每条一行；或者一段不超过 40 个字。细节放在演讲者备注里。
- **字号**（按 1280×720 画布）：标题 40–48px，正文 24–28px，图注 16–18px。最小不低于 16px。
- **对齐**：正文左对齐，只有封面标题和单个大数字可以居中。

## 4. 整套

- 封面一页：标题 + 讲者 + 日期。
- 超过 10 页时，第二页给出议程。
- 结尾页写结论和需要听众做的事（决定、批准、行动），不单独放“谢谢”“Q&A”页，除非用户要求。
- 选一个贯穿全套的视觉母题：例如图标都放在同色圆底里、图片都用同一种圆角。不要用色条或装饰线当母题。
- 版式要有变化：不要连续三页都是“标题 + 三条要点”。在双栏、整页图表、关键数字、对比栏、时间线之间切换。
- 配色从主题出发，一个主色占主导，一个强调色只给要突出的东西。可以“深—浅—深”：封面和结尾用深色，内容页用浅色。

## 5. 版式参考

| 内容 | 版式 |
|---|---|
| 一个关键结论 + 证据 | 左侧两三行文字，右侧一张图表 |
| 一个必须记住的数字 | 数字 120–160px，下面一行说明它意味着什么 |
| 两个方案比较 | 左右两栏，同样的维度逐行对齐 |
| 流程或架构 | 整页示意图，箭头上写清楚动作 |
| 进度或历史 | 横向时间线，标出今天的位置 |
| 多个并列要点 | 2×2 网格，每格一个图标 + 一个短标题 + 一句话 |

## 6. 不要这样做

- 标题下面加一条装饰短横线。
- 页面顶部、底部、侧边的装饰色条；卡片一侧的彩色竖条。
- 纯文字页，或者满页要点。
- 每页同一个版式。
- 正文居中。
- 低对比：浅底浅字、深底深字，图标颜色看不清。
- 默认用蓝色或米黄色背景，与主题无关。
- 文字超出页面或被裁掉。

## 7. 检查

- 用浏览器打开，按 `O` 进总览，整体看一遍节奏和版式变化。
- 逐页确认没有文字溢出画布、没有元素重叠。
- 只读标题，检查论证是否连贯。
- 发布后把链接给用户，说明快捷键：`F` 全屏，←/→ 翻页。
